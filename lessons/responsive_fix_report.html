Responsive Resizing Fix Report

The Issue: Asymmetric Shrinking

Even though the left and right sides were 50% width each, the content inside them was different.

  • Left Side: "HUMAN" text (approx 60px wide) + 5 circles
  • Right Side: "COMPUTER" text (approx 100px wide) + 5 circles

Because "COMPUTER" took up more horizontal space, the 5 circles on the right had less remaining space than the circles on the left. As the screen shrank, the right-side circles hit their minimum size faster and looked smaller.

1. Fixing the Text Width

🔴 Before (Variable Width)

The text took up only as much space as it needed. "HUMAN" was narrow, "COMPUTER" was wide.

.score-bar p {
    font-size: 18px;
    margin: 20px;
    /* width: auto (default) */
}

🟢 After (Fixed Width)

We forced both labels to be exactly 120px wide. Now both sides have identical space left for the circles.

.score-bar p {
    font-size: 18px;
    margin: 20px;
    width: 120px; /* Force equality */
    text-align: center;
}

2. Controlling the Circle Containers

🔴 Before

The container for the results just sat there. It didn't know it was supposed to fill the rest of the space.

.human-results,
.comp-results {
  display: flex;
}

🟢 After

We added flex: 1. This tells the circle container: "Take up all the remaining space that the text label isn't using."

.human-results,
.comp-results {
  display: flex;
  flex: 1; /* Fill remaining space */
  justify-content: center;
}

Now the math is perfect: (50% screen width) - (120px text) = Circle Space on both sides.

Alignment Fix Report

Why it wasn't centering:

The score bar was using justify-content: space-evenly. This distributes empty space equally between items. However, the items themselves were different sizes ("HUMAN" is 5 letters, "COMPUTER" is 8 letters). This caused the visual center point to shift slightly to the left, making it look off-center.

How we fixed it:

We grouped the elements into two containers (Left Side and Right Side) and gave them both flex: 1. This forces each side to take up exactly 50% of the screen width, meeting perfectly in the middle regardless of how long the text inside them is.

1. HTML Structure Changes

🔴 Before (Flat Structure)

All items were direct children. There was no way to control the width of the "Human" side vs the "Computer" side independently.

<div class="score-bar">
  <!-- Just a list of items -->
  <p>HUMAN</p>
  <div class="human-results">...</div>
  
  <!-- Center point was vague -->

  <div class="comp-results">...</div>
  <p>COMPUTER</p>
</div>

🟢 After (Grouped Structure)

We created two wrapper divs. This allows us to balance the left and right sides perfectly.

<div class="score-bar">
  <!-- Left Group (50% width) -->
  <div class="score-side left-side">
    <p>HUMAN</p>
    <div class="human-results">...</div>
  </div>
  
  <!-- Right Group (50% width) -->
  <div class="score-side right-side">
    <div class="comp-results">...</div>
    <p>COMPUTER</p>
  </div>
</div>

2. CSS Styling Changes

🔴 Before

Relied on space-evenly which only balances the empty gaps, not the content size.

.score-bar {
  display: flex;
  justify-content: space-evenly;
  align-items: center;
  /* No control over item widths */
}

🟢 After

Uses flex: 1 to force equality.

.score-bar {
  display: flex;
  justify-content: center; /* Center the groups */
}

.score-side {
  flex: 1; /* Takes exactly 50% width */
  display: flex;
  align-items: center;
}

/* Push content toward the center line */
.left-side { justify-content: flex-end; }
.right-side { justify-content: flex-start; }
